# Milestone 4 – Page & Pine Open Library SPA

This is a separate Milestone 4 application. Keep your Milestone 3 folder unchanged.

## Files
- `index.html` – single-page application and Mustache templates
- `css/style.css` – responsive styling
- `js/script.js` – jQuery AJAX, rendering, pagination, navigation, and details

## Run locally
1. Unzip the project.
2. Open the `milestone4` folder in VS Code.
3. Run `index.html` with Live Server, or use another local static web server.
4. Search for a book and test Grid/List, pagination, the Fantasy collection, and book details.

Internet access is required because jQuery, Mustache.js, Google Fonts, and Open Library are loaded online.

## Before submitting
- Confirm that Fantasy is the same subject you used in Milestone 3. If your Milestone 3 collection used another subject, change `/subjects/fantasy.json` in `js/script.js` and update the visible labels in `index.html`.
- Copy this folder into your existing GitHub repository without changing the Milestone 2 or Milestone 3 folders.
- Publish the `milestone4` folder to Azure and test the live URL.
- Take your own screenshots of the working app for the PDF report. Do not use mock screenshots.
- Replace the placeholder URLs in your report with your actual Azure and GitHub links.
